Protection locale de démonstration

NexaShield analyse uniquement les éléments que tu saisis ici. La protection générale de ton appareil n'est pas activée.

01 — Analyse d'un lien

Colle un lien pour rechercher des signes courants d'arnaque. N'ouvre pas le lien pour le tester.

02 — Analyse d'un message

Colle le texte d'un SMS ou d'un message suspect. Supprime d'abord les données personnelles.

03 — Protéger ses informations

Quelques règles essentielles :

  • N'envoie jamais tes mots de passe par message.
  • Active la double authentification.
  • Installe les mises à jour de sécurité.
  • Ne communique jamais un code reçu par SMS à un inconnu.
  • Vérifie les demandes urgentes par un autre canal officiel.

Cette page ne supprime pas tes historiques et ne modifie pas les réglages de confidentialité de ton appareil.
